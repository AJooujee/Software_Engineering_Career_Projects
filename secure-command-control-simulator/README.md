# Secure Command-and-Control Message Processing Simulator

A Java and Python software engineering project that simulates secure
and reliable command exchange between a control station and a remote unit.

## Planned Features

- TCP/IP client-server communication
- JSON command messages
- Object-oriented command processing
- HMAC-SHA256 message authentication
- Replay and duplicate-message detection
- Sequence-number validation
- Timestamp-expiration checks
- Command acknowledgements
- Timeout and retry handling
- State-dependent command execution
- Structured audit logging
- JUnit unit and integration testing
- Docker-based execution

## Technologies

- Java 21
- Python 3
- Gradle
- JUnit 5
- TCP/IP
- JSON
- Docker
- Git and GitHub
